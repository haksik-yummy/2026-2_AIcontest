결빙 위험도 API

전체 입력·출력 계약은 service/API.md에 있습니다. 아래 링크는 이 서버에서 바로 동작합니다. 값은 분석 추정이며 실제 노면 결빙을 확인한 값이 아닙니다.

조회

요청내용
/api/v1/metadata기간, 기준, 모델과 검증 성능, 수신 상태
/api/v1/segments?route=호남선구간 GeoJSON
/api/v1/segments/TD-014구간 상세와 지표 근거
/api/v1/segments/SH-044/timeseries?from=…시간별 추정값과 관측소 실측값
/api/v1/status?mode=history&at=…그 시각의 구간별 상태
…&format=geojson같은 값을 GeoJSON으로
/api/v1/current최신 수신값. 없거나 오래되면 값을 비움
/api/v1/nearest?lat=35.6&lon=126.75가장 가까운 구간

경로

요청내용
/api/v1/route-risk/stretch?…노선 km 범위의 위험 (키 불필요)
POST /api/v1/route-risk경로 좌표를 받아 지나는 구간과 통과 시각의 값
GET /api/v1/naver/directions?start=&goal=&at=네이버 Directions 5 경로와 위험 요약 (서버 키 필요)
curl -X POST http://localhost:8000/api/v1/route-risk \
  -H "Content-Type: application/json" \
  -d '{"path": [[126.8,35.6],[126.81,35.62]], "mode": "history", "at": "2025-01-28T06:00+09:00"}'

운영

요청내용
/api/v1/ops/briefing?…시군·노선별 우선 구간
/api/v1/ops/vulnerable상습 결빙구간과 위험 등급 비교
/api/v1/reference/cctv최신 CCTV 도로날씨 지점

입력

POST /api/v1/ingest는 Authorization: Bearer 토큰이 맞을 때만 받습니다. 서버의 ICING_INGEST_TOKEN 환경변수가 없으면 닫혀 있습니다.

상태의 뜻

표시뜻
조건 미충족선택한 결빙 조건에 해당하지 않음. 안전 판정이 아님
결빙 가능 조건추정 노면온도 ≤ 1°C, 습도 ≥ 70%, 수분 공급
결빙 가능 조건 + 모델 예측위 조건이고 분류 확률도 임계값 이상
정보 부족수신 자료가 없거나 신선도 기준보다 오래됨. 상태를 만들어 내지 않음
